# Hola, soy Adri

Consultor senior de analítica digital en **The Cocktail (VML)**, especializado en Adobe Analytics, Tealium iQ y GA4.

Construyo herramientas para capturar, depurar y comparar beacons de tracking.

## Herramientas

- **[Cortadería Splitter](https://monkeycore.github.io/Cortaderia/)** — Parser visual de beacons: pegas una llamada de Adobe Analytics o GA4 y la desglosa variable a variable, con historial y diff entre trazas.
- **[Entrena](https://monkeycore.github.io/Gymapp/)** — Registro de entrenamientos de fuerza para el móvil, con temporizador de descanso e historial de 13 semanas.

## Stack

`Adobe Analytics` `Adobe Target` `Tealium iQ` `GA4` `Python` `Playwright` `JavaScript`
