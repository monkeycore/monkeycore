# Hola, soy Adri

Consultor senior de analítica digital en **The Cocktail (VML)**, especializado en Adobe Analytics, Tealium iQ y GA4.

Construyo herramientas para capturar, depurar y comparar beacons de tracking.

## Herramientas

- **[Imaginarium](https://monkeycore.github.io/imaginarium/)** — Analizador visual de beacons de Adobe Analytics Event Stream, con modo diff/overlay y persistencia local.
- **[Cortadería](https://github.com/monkeycore/Cortaderia)** — Herramienta para parsear y comparar beacons de Adobe Analytics y GA4, compañera de Imaginarium.
- **[Viscum](https://github.com/monkeycore/Viscum)** — Extensión de Chrome para capturar beacons de Adobe Analytics, Web SDK, GA4 y Tealium en tiempo real.
- **[Gymapp](https://monkeycore.github.io/Gymapp/)** — PWA de seguimiento de entrenamientos, con temporizador de descanso e historial de 13 semanas.

## Stack

`Adobe Analytics` `Adobe Target` `Tealium iQ` `GA4` `Python` `Playwright` `JavaScript`
